## 备注

1. **本机 `slidep` shim 失效**：`binaries/node/versions/22.22.2-6/slidep` 查找的路径是
   `$HERE/node_modules/@tencent/slidep/dist/index.js`，但引擎实际装在
   `$HERE/lib/node_modules/@tencent/slidep/dist/index.js`（全局 npm 前缀），shim 永远判定「引擎未就绪」
   并 exit 69。**绕过方式：直接调引擎**
   `node.exe <node目录>/lib/node_modules/@tencent/slidep/dist/index.js <create|lint|upsert-dsl> ...`。
   注意 `slidep create` 产出的是 **0 页**的空文件（lint 返回的 `slide_count: 1` 是「被校验的 DSL 页数」，
   不是文件页数），所以第一页用 `--page-index 0` 追加即可，不会产生空白首页。
2. **`slidep screenshot` 在本机不可用**：报
   `render failed: The argument 'filename' must be a file URL object... Received 'file:///workspace/node_modules/.pnpm/@tencent+docs-slide-view-sdk-node@...'`
   ——渲染 SDK 按 pnpm 布局路径解析，本机是 npm 布局，找不到实现。**副作用：Agent 侧看不到渲染图**，
   只能手工核算高度。本次靠「每页累加高度 ≤ 720」+「lint 的 child-containment 报错」兜住，
   页 08 / 13 各因此抓出一处 20px 溢出（B 区 544 含 paddingTop 20，内容可用只有 524，容易漏算）。
3. **SlideDSL 的两个坑**：
   - `Text` 只认 `<span style={{...}}>`，写 `<b>` 不生效（会被当普通文本或丢弃）；
   - SVG `<text>` 里的 `<tspan>` 是**保留**的（已抽查 slide6.xml，四层标签文字完整）。
4. **SKILL 的「禁读其他 PPT 项目源码」边界**：本次未复用任何既有 deck 的 jsx / 视觉选择，
   但从 `output/认知副驾项目汇报/assets/` 看到有 10 张真实界面截图可作 P0 材料图——本次未使用，
   留作后续（若要把手机端做成实录页，真机截图比示意图更有说服力）。
