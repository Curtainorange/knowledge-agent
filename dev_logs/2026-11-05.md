## 备注（追加）

- **本机 TLS 坑**：首次真机调用报 `CERTIFICATE_VERIFY_FAILED self-signed certificate in
  certificate chain`。前台 `httpx.post` 四种方式全 200，只有后台 `trust_env=False` 报错。
  结论：本机 `HTTPS_PROXY=http://127.0.0.1:56818` 做 TLS 中间人，其根证书在 **Windows
  系统证书库**里、不在 certifi 里。修法是用 `ssl.create_default_context()` **重试一次**
  （会加载系统库），**不是 `verify=False`**。企业网络/本地代理环境都会撞这个。
- **`unhandled` 那类坑的本质**：模型对「系统能做什么」的认知如果和代码里的实际能力
  不一致，它就会说出「做不了」。所以 `AGENT_ROUTE` 的能力表不只是分类表，**它是模型
  对自身能力的唯一知识来源**，改能力必须同步改这张表，否则会出现「明明有按钮却说没有」。

# 10:30 追加 · 气泡里的 Markdown 标记（用户截图问「这些 * 是啥」）

## 现象与根因

联网找材料的回复里满屏 `**第一阶段（0-6 周）**`、`### `、`- `。不是乱码，是模型按
Markdown 排版，而气泡是纯文本容器：

```js
bubble.textContent = message.content || '';   // 旧：不解析任何标记
```

`.bubble` 只有 `white-space:pre-wrap`（保留换行），所以标记原样露出来。
这是**渲染缺失**，不是模型写错。

## 改法（用户选的是「气泡做极简 Markdown」）

新增 `CCA.bubbleHtml(text)`（纯函数，挂在 CCA 上，可在 Node 里测），只认四种写法：
`**粗体**` / 行首 `###` 小标题 / 行首 `- * •` 列表 / 裸 `http(s)` 链接。
其余一律当文本。

三条实现约束：

1. **先转义再替换**。正文里可能有模型转述的网页原文，属于第三方不可信内容；
   转义必须在任何标签拼接之前完成（插进去的 `<strong>/<a>` 是这一层自己生成的）。
2. **不生成块级元素**。气泡排版依赖 `pre-wrap` 的换行，塞 `<ul>/<h3>` 会把行距与缩进
   全打乱；列表只把行首符号换成 `•`，保留逐行结构。
3. **链接的边界**。字符类里排除裸 `&`、只放行 `&amp;`——转义后 `"` 已变成 `&quot;`，
   放行裸 `&` 会把结尾的引号实体一起吞进 href；而查询串里的 `&` 一定是 `&amp;`。
   句末的 `。`/`,`/`.` 之类要剥掉再回填，否则会进 href。

## 守卫改造（不是删掉）

`test_user_message_does_not_use_innerhtml` 断言 `bubble.textContent =` 且**禁止**
`bubble.innerHTML` —— 它当时是对的（气泡里只有纯文本），而且正是它第一时间把这次
改动拦了下来。按复盘第 18 条，**改反断言而不是删守卫**：换成
`test_bubble_text_goes_through_the_escaping_renderer`，钉三件事：
内容必须经 `CCA.bubbleHtml`、不许直接拼 `message.content`、该函数第一行必须是 `esc`。

Node 侧新增 20 条断言（裸星号清零、转义后仍能加粗、`javascript:` 不给可点、
句末标点/`&amp;`/中文括号的边界、未闭合 `**` 原样保留等）。
