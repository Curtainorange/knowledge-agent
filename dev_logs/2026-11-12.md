## 备注

### 1. 截图怎么拍的（关键做法，将来重拍照这个来）

- **登录态不必知道密码**：账号密码是 PBKDF2 哈希、无法反推。改用项目自己的
  `app.core.security.create_access_token(user_id, token_ver)` 签一枚临时令牌，
  再用 Playwright 写进前端约定的 `localStorage.cc_access_token` —— **全程不改数据库、不改密码**。
  临时令牌文件与引导页用完即删（本次已删）。
- **不能用 MCP 的浏览器截图落盘**：`mcp__browser__tab_screenshot` 只返回图像内容，拿不到文件。
  headless Edge `--screenshot` 也不行：`--window-size` 不生效（输出 1080×601），
  且会把站内推送弹窗与 PWA 安装条一并拍进去。
- **可用方案**：`pip install playwright` + `chromium.launch(channel="msedge")`（复用系统 Edge，
  不下载浏览器）。`viewport 1700×935` + `device_scale_factor=2` → 输出 3400×1870，转 JPEG 后约 200KB/张。
  Edge 扩展注入的头像浮层与黑圈按钮在 headless 下**不存在**，画面干净。
- 需屏蔽的站内浮层：`.notify-stack`（推送卡片）；PWA 安装条用
  `localStorage.pwa_install_dismissed='1'` 关掉。
- 对话页的滚动：`page.mouse.wheel(0, -1150)` 比切 DOM 容器更省事（`#history-list` 选会话，
  对话区滚动容器类名未暴露）。
- 「认知简报」页刷新即丢状态（结果只在前端），要截必须现场点一次「生成」再等「分析完成」，
  且**等 5 秒让 toast 自动消失**，否则遮住正文。

### 2. slidep 的字体告警是噪音

每次 lint 都会打印「couldn't load font 微软雅黑 … falling back to Sans」。那是**检查器渲染环境**没有该字体，
