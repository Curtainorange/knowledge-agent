## 备注（本次扩展的关键教训）

1. **「块数上限」必须按字数而非输入单元数设计**：epub 碎片章节（目录、版权页各算一章）
   会把按章切块的块数顶爆——09-28 修过切块合并，本次 MAX_CHUNKS 又被 19.9 万字真书顶着 16 上限，提到 24。
2. **topic 通道的标签必须同源**：影子主张 topic 用书名时与笔记主题词永不相交（书×笔 0/20 入选）；
   换成通读时 LLM 打的领域标签后仍未选中（名额竞争），最终靠「跨来源加权」才进候选——
   三个环节（标签同源、噪声过滤、名额公平）缺一不可。
3. **判定 0 矛盾 ≠ 检测失败**：先查配对构成再下结论。本轮 16 对书×笔全部是印证关系，
   「判得准」包括「判得出没有矛盾」。
4. 排查利器：`_candidate_pairs` 可以脱离 LLM 单独跑（纯本地统计），先看对构成再烧判定钱。
5. **slidep 改页两个坑**：`upsert-dsl` 默认 append（覆盖须传 `--page-index`）；present_files
   预览用 PowerPoint 锁住 pptx，slidep save 报 `occupied`——改页前先 `Stop-Process POWERPNT`。
