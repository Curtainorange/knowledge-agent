# 开发日志

本目录用于记录每日开发进展。每个自然日对应一个日志文件：

```
dev_logs/
├── README.md        # 说明文件
├── TEMPLATE.md      # 日志模板
└── 2026-09-09.md    # 示例：当天的日志
```

## 规则

- 日志文件命名：`YYYY-MM-DD.md`（当天日期）。
- 每天自动生成当日日志文件（由每日定时任务触发）。
- 记录内容：**今日完成**、**待办事项**、**明日计划**，「今日完成」由开发过程中实时追加。
- 开发会话中每完成一个事项，请顺手更新当天日志的「今日完成」。
- 没有工作的一天，只需对方.com空白保留模板即可，不要删除。

## 如何查看

- 最近一天：直接打开 `dev_logs/` 里日期最新的 `.md` 文件。
- 时间线：按文件名排序即可看到历史。
