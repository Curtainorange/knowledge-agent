# 开发日志

本目录用于记录每日开发进展与跨日期的长期沉淀。

```
dev_logs/
├── README.md              # 说明文件（本文件）
├── TEMPLATE.md            # 每日日志模板
├── YYYY-MM-DD.md          # 每日日志（今日完成 / 待办 / 明日计划 / 备注）
├── 复盘与教训.md           # 跨日期沉淀：bug 复盘（现象 → 根因 → 修复 → 教训）
└── 设计决策与经验.md        # 跨日期沉淀：架构决策与可复用经验
```

## 规则

- 日志文件命名：`YYYY-MM-DD.md`（当天日期）。
- 记录内容：**今日完成**、**待办事项**、**明日计划**、**备注**；「今日完成」在开发过程中实时追加。
- 开发会话中每完成一个事项，请顺手更新当天日志的「今日完成」。
- 没有工作的一天，保留空白模板即可，不要删除。

## 长期沉淀（跨日期，建议优先读这两份）

- **`复盘与教训.md`** —— 出过的 bug 复盘，每条含「现象 → 根因 → 修复/防回归 → 教训」，按主题分组。
- **`设计决策与经验.md`** —— 架构与实现决策、「为什么这么做」、可复用经验，按主题分组。

> **约定：所有「完成的任务」与「沉淀的经验」都写在本目录**，不依赖任何工具的私有目录，
> 以保证换用其他工具 / 智能体时信息依然可读。

## 如何查看

- 最近进展：打开日期最新的 `YYYY-MM-DD.md`。
- 历史时间线：按文件名排序即可。
- 想快速了解「踩过哪些坑、做过哪些关键决策」：直接读 `复盘与教训.md` 与 `设计决策与经验.md`。
