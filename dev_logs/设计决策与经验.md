## 一、鉴权与账号安全

- **改鉴权的切入点是依赖，不是端点**：只改 `deps.get_user_id` 的实现，所有既有端点就
  自动获得鉴权——因为这些端点本来就依赖它。改动面最小，不必逐个端点改造。
- **PBKDF2 把迭代数写进哈希串**（`pbkdf2_sha256$iter$salt$hash`）：将来调高全局迭代数
  不会锁死老用户（校验用串内参数，重新哈希才用新参数）。
- **JWT 解码必须显式传算法白名单**（`algorithms=["HS256"]`），否则存在 alg 混淆 /
  alg=none 攻击面。
- **必须区分令牌类型**（access / refresh）：否则长期 refresh 凭证可直接访问业务接口，
  等于绕过 access 的短期过期策略。
- **登录失败统一提示 + 拉平耗时**（账号不存在时也跑一次哈希），防账号枚举。
- **限流要双维度取最严**：只按账号会被「每个账号试几次」广撒网绕过；只按 IP 会在 NAT 下
  连带误伤。**不存在的账号也要计数**，否则「是否被锁」会变成账号存在性的旁路探测。
- **限流时间基准用 `time.monotonic()`**：NTP 校正或用户改系统时钟都不会让锁定提前失效。
- **内存桶要懒惰清理 + 设桶数量上限**，否则海量随机 username 攻击会让内存无界增长。
- **JWT 吊销不必引存储**：把「令牌版本」放进 payload、与用户表当前版本比对，改密/注销
  即 +1，所有旧 access/refresh 同时失效；比维护黑名单简单，也不用等自然过期。
- **改密要同时返回新令牌**：版本 +1 会踢掉所有设备（含本机），不回送新令牌的话用户
  改完密码立刻被自己登出——功能正确但体验莫名其妙。
- **测试里查库断言必须用服务端签发的真实 `user_id`**，不能用用户名代替（仓储 guard 会拦截）。
- 验证「固定 JWT_SECRET 生效」的方法：起服务 → 登录取 token → **重启服务** → 用旧 token
  请求 `/auth/me`，同时确认启动日志里没有「临时密钥」告警。

## 二、数据库与事务

- **慢操作绝不能压在数据库写事务里**：模型加载 / 网络下载 / 向量计算一旦被包进写事务，
  SQLite 的**库级写锁**会让其它所有写请求连锁 500（现象：`database is locked`）。
  修法：先 commit 落库释放锁，再补算向量；连接 `timeout` 提到 30s。
- **失败冷却状态不要挂在「每请求新建」的对象上**：`build_embedding()` 每请求新建实例，
  而「加载失败冷却」状态存在实例上 → 冷却永远不生效，每次录入都重新尝试下载并卡住。
  修法：按 backend 复用单例 + 提供 `reset_embedding_cache()`。
- **建表路径必须一致**：`create_all`（dev/测试）与 alembic（生产）都要声明约束与索引，
  只写一处 = 环境相关 bug（参见「复盘与教训.md」第 1、2 条）。
- **书籍全文先整本存 SQLite（P0）**：量级上来再改对象存储 + 字符偏移索引。

## 三、模型调用与计费

- **别让模型做算术**：凡统计数字会进入产出的地方（主题分布、冲突同比），计数必须**本地聚合**——
  模型算式不可靠，而「12 篇里 9 篇停在入门层」这种数字恰恰是结论的依据，错一个就不可信。
  模型幻觉出来的 `item_id` 一并丢弃。
- **降级要分级**：部分结果比「抱歉出错了」有用（如归类失败仍保留主题分布）。
- **模型输出形态会变，且只在真机暴露**：裸换行 JSON、markdown 围栏、前后夹带文字都会让
  标准解析失败。加固共享解析层（`strict=False` + 截取最外层花括号），并录制真实产出做
  **golden set** 回放——这是唯一能在无网 CI 里拦住这类回归的手段。
- **计费的失真往往不在单价而在口径**：忽略「缓存命中价约为未命中 1/50」会高估一个量级；
  同理高峰价是空闲的两倍，写死单一单价必然错一半时间。
- **提示词版本化要「文本与版本同处、指纹锁死」**：版本与文本分开放，改文本的人容易忘
  bump 版本。解法：同一个 PromptSpec 同时放两者 + golden 记 sha256，改了文本 hash 不匹配
  测试立刻红。**防脱节的不是纪律，是测试。**
- **推送抑制闸门全放本地**：去重 / 收敛 / 免打扰是可枚举事实，代码短路判断即可；
  交给模型 = 为「判断要不要打扰」再花一次调用还引入不稳定。
- **置信度校准要把「模型自信」与「证据充分」分开**：样本太少时 0.9 也打折；
  阈值类参数不要写死 0.5，要跟证据量走。
- **走 `reasoning=off` 省钱**：归类、生成式提问等不需要思考模式的任务显式关掉，省下的
  溢价直接体现为成本。

## 四、前端

- **项目全部页面共用一份 `style.css`**（原生 CSS、无框架、无外部依赖）：改样式只需改这一处。
  改前先收集所有 HTML 用到的 class + 校验花括号平衡，确保不遗漏、不破坏。
- **ASI 坑**：以 `[` 或 `(` 开头的续行会被 JS 解析成对上一行结果的索引/调用，
  **语法检查查不出来、只在运行时崩**。用 `node --check` 兜底 + 具名函数调用规避。
- **算「选中位置」必须与后端全文偏移体系对齐**：用 `Range` + 预置 range 的
  `toString().length` 得到章节内字符偏移，再叠加 `chapter.char_start` 得到全文偏移——
  这样才能做高亮与回溯。
- **重新渲染内容后必须恢复 `scrollTop`**，否则每存一次知识就跳回顶部。
- **按比例恢复滚动位置要考虑异步资源**（插图加载会撑高布局）：在图片 `load/error` 后
  再校准一次；这类图片不要加 `loading="lazy"`（会让 `complete` 长期为假，校准不触发）。
- **验证「想法进了向量」的手法**：用**只出现在想法里**的措辞去挖，命中即证明不是靠原文匹配。
- 纯 CSS 足够用：品牌 logo 用 `::before` + 渐变、柱状图用 `flex` + 高度百分比归一化，
  不必为一个小视觉引第三方库。

## 五、工程方法

- **埋点要自带 SAVEPOINT**：整事务 rollback 会带走调用方未提交的业务改动。
- **模块级惰性单例 + 测试改阈值 = 跨用例污染**（表现为「单独跑过、一起跑挂」）：
  夹具每个用例重建实例来隔离。
- **后台线程与测试天然冲突**：用 `worker_enabled` 开关 + 显式 `run_once()` 把执行时机
  交回测试，比让测试去「等」后台行为可靠得多。
- **改 `run_once` 这类公共编排要检查旧断言**：加新周期任务会打破旧测试对 `succeeded == N`
  的精确断言；修法是用 monkeypatch 关掉新开关，让旧测试聚焦原意图。
- **commit message 里有反引号必须走 `-F <file>`**：否则 shell 命令替换会吃掉内容。
- **`git add -A` 会带入 `scripts/` 下的临时文件**：提交后需摘除（未 push 时
  `rm + git add -A + git commit --amend --no-edit` 安全）。
- **错误码也是信息**：跨用户越权应返回 403 而非 404，否则等于帮攻击者验证账号枚举。
- **周期任务不需要调度器状态**：把「每周一次」表达成含 ISO 周的**幂等键**，worker 每轮
  无脑 ensure 即可，省掉 cron 表达式与「上次执行时间」的持久化。

## 六、环境与调试

- **判断「连不上」要分层看**：DNS 能解析 ≠ TCP 可达 ≠ 应用能拿到数据。
  `curl -w "HTTP %{http_code} dns=%{time_namelookup} connect=%{time_connect}"` 一眼看清卡在哪层。
  另外：用户说的「有网」通常指能上网，**不代表目标域名可达**。
- **模型源被阻断的通用解法**：换可达镜像预取到本地（如 ModelScope），再用 onnxruntime
  自己推理，彻底摆脱运行时对 HuggingFace 的依赖——顺带获得完全离线能力。
- **环境有 safe-delete 钩子会拦截 `os.remove`**（走 trash 失败会抛 OSError）；删临时文件
  用 `os.unlink` 绕过。
- **读响应头要不区分大小写**：urllib 转 dict 后键可能被小写化，`headers.get("Retry-After")`
  会取不到。
- **上传不用 multipart**：`python-multipart` 未装，raw body + 文件名 header 更省事；
  但**中文文件名必须 URL 编码**（HTTP header 只接受 latin-1）。
- **epub 不引入 ebooklib**：标准库 `zipfile` + 已装 `bs4` 就够，少一个依赖少一个坑；
  图片相对路径要**双目录回退**（先相对 xhtml 所在目录，再相对 OPF 目录）。
