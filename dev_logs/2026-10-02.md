## 备注

1. **计数口径**：「全量 N 项绿」此前用 `--collect-only -q` + awk 求和，与 pytest
   汇总存在偏差；自本日起以 pytest 汇总行（`N passed`）为准。
   另注意：`pyproject.toml` 的 addopts 已含 `-q`，命令行再传 `-q` 会叠成 `-qq`
   把汇总行吞掉——拿计数时别重复传，或直接 `pytest --no-header -p no:warnings`。
2. **M1 的核心取舍**：底部导航纯 CSS 实现（fixed + 横滑 + snap），零 JS 零 HTML
   结构变更——桌面布局零变化，任何页面都不用改导航 markup。
3. **M3 的手势边界**：翻章与滚动的共存靠「水平主导」判定（|dx|≥60 且>|1.5dy|）；
   抽屉上滑关闭只挂 panel-head——把手势绑在滚动容器上必然误触，绑在不滚动的
   区域是零冲突解。划词弹层移植到触摸端走同一 touchend，与翻章互斥分支。
4. 工作区有用户自己的未提交内容（周工作汇报 md/pptx），与开发提交隔离。
