# STORY.md — 认知副驾 · 本周项目汇报（2026-10-15）

## ① 用户意图对齐

- **目标受众**：导师 / 课程周报场合。听众懂技术、会追问实现取舍，但不必假定其熟悉 Agent 工程的新名词。
- **核心目标**：讲完希望导师相信三件事——① 这一周不是"又堆了功能"，而是**把新学到的四层工程概念在自己项目里逐层落了地**；② 手机的改造是**有边界、有取舍的工程决策**，不是套壳；③ 汇报人对"怎么判断问题出在哪一层"有方法论，而不是会背名词。
- **PPT 长度**：16 页。Hero 配额 4 页（25%）。
- **视觉调性**：靛蓝技术 / 克制 / 工程感 / 结构化 / 直给信息（不卖萌、不说教）。
- **内容边界**：
  - 必讲：Prompt / Context / Harness / Loop 四层名词的含义与边界；每层在项目里的**具体对应实现**；MCP 是什么、项目里怎么用；手机端 M1–M5 的改动与关键取舍；安全边界。
  - 不讲：口号式产品愿景、逐条罗列测试用例、与本次主题无关的历史功能。
  - 禁碰：装饰性堆砌、网格/纹理叠加背景、把专有名词只当名词背（每个名词必须落到"我怎么做 / 为什么这么做"）。
