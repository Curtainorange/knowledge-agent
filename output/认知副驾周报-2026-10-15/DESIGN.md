## 1. 画布与全局母版

- **画布**：1280 × 720 px（16:9）
- **页面 padding**：上 34 / 左右 72 / 下 22 → 左右安全边距 72px，内容可用宽 **1136px**

| 母版区 | 垂直位置 | 高度 | 内容规则 |

## 2. 颜色系统

### 2.1 主色板（4 hex）

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| **主色** | `#3730A3` | 大色块、标题栏底、章节扉页底、图示主描边 |
| **辅色** | `#EEEDFE` | 卡片底、图示填充、标签胶囊底 |
| **强调色** | `#0EA5E9` | **仅**出现在视觉焦点：巨型数字、关键阈值、当前步高亮 |
| **文本主色** | `#1F2430` | 标题与正文 |

### 2.2 中性结构色（不计入主色板，全篇不作强调）

| hex | 用途 |
| :--- | :--- |
| `#FFFFFF` | 画布底色、卡片底色 |
| `#6B7280` | 次要文字、引导句、页脚 |
| `#E5E7EB` | 分割线、卡片描边 |
| `#F6F7FB` | 区块浅底（图示外框、表头底） |

### 2.3 色彩面积分配

| 色彩角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 主色 `#3730A3` | ≤ 45% | 仅扉页（整幅）与图示主块；内容页不超过 25% |
| 辅色 `#EEEDFE` | ≤ 30% | 卡片底、图示填充 |
| 强调色 `#0EA5E9` | ≤ 10% | 常规页 ≤ 5%；Hero 页（P1/P6/P13/P16）可到 15–20% |
| 中性色 | 剩余 | 文本、页脚、边框、留白 |

**色彩节奏**：P1 / P3 / P5 / P10 / P12 / P16 为主色主导页（扉页/封面/结束，主色面积最大）；P4 / P13 为强调色爆发页（锚点数字）；其余为中性主导页。至少 2 页的色彩比例与其他页显著不同 ✓

### 2.4 渐变与半透明

- 章节扉页底：`linear-gradient(120deg, #3730A3 0%, #4F46E5 55%, #0EA5E9 100%)`（仅 P1/P3/P5/P10/P12/P16）
- 卡片浅底：`rgba(55,48,163,0.04)`；图示区块：`#F6F7FB`
- 卡片浮起：`boxShadow: '0 6px 24px rgba(31,36,48,0.07)'`
- 元素重叠：底层 `opacity: 0.12`
- **禁止**：网格纹理、噪点、发光 / 霓虹、高饱和撞色铺满 ≥1/3 页

## 4. 信息密度与留白

- 常规内容页留白 ≤ 35%；封面 / 扉页 / 结束页 40–50%（围绕核心元素，非均匀散布）
- 单页字数：内容页 180–260；扉页 30–40；封面/结束 30–40
- 卡片填充率 ≥ 85%；同行兄弟卡的「标题块 / 正文块 / 尾部标签」三段 y 轴对齐，误差 ≤ 16px
- 卡片尾部元素（标签条 / 判断句条）一律钉到卡片底（`justifyContent: 'space-between'`）
- **每个视觉锚点周围留 ≥ 40px 呼吸空间**
- 文本承载一律横排，不旋转

## 7. 生成前自检清单（逐页对照）

1. ☐ A/B/C 三区齐全（封面 / 扉页 / 结束页除外 C 区页码仍在）
2. ☐ A 区标题块无装饰小图；全篇标题位置严格一致
3. ☐ B 区主视觉占 ≥ 30%（Hero 页 ≥ 40%）或含 ≥ 92px 锚点数字
4. ☐ 仅使用 §2 声明的色彩；强调色只落在焦点元素
5. ☐ 与上一页版式不重复；留白 ≤ 35%（扉页/封面/结束页除外）
6. ☐ 相邻页视觉重量差异显著（最大元素面积比 > 1.5:1 或结构明显不同）
7. ☐ 高度累加 ≤ 720px；无 `flex: 1` 未算高度
8. ☐ 每页 ≥ 1 个视觉锚点（≥ 44px 元素 或 ≥ 40% B 区图示）
