# DESIGN.md — 认知副驾 · 用户功能展示

> 视角：一个实际在用的学习者，打开产品后能做什么、看到什么。
> 所有页面配图均为**真实使用界面截图**（本机 8010 服务、真实账号数据、真实模型输出），非示意图。

## 一、全局视觉约定

### ① 画布与安全区
- 画布 1280×720；padding 上下 60 / 左右 60；内容区 1160×600。
- 页尾：右下角页码（14px），y 落 670 附近，全篇固定；封面 / 章节页 / 结尾页不加。

### ② 配色（活力紫，取自产品自身 UI）

| 槽位 | Hex | 用途 |
|---|---|---|
| 主色 | `#7C3AED` | 章节编号、标题强调、要点标记、进度条 |
| 辅色 | `#C4B5FD` | 分隔线、标签底、次要图形 |
| 强调 | `#F472B6` | 关键数字、核心结论、唯一焦点 |
| 浅底 | `#F7F3FF` | 结论条 / 说明条底（每页 ≤2 处） |
| 底色 | `#FFFFFF` | 页面主背景 |
| 正文 | `#1E1B4B` | 主文字 |
| 次要文字 | `#6B7280` | 注释、图注 |

色彩纪律：主色 ≤60%，强调色 ≤10% 且一页最多 2 处；禁阴影；禁渐变铺面。

### ③ 字体
- 中文：**微软雅黑**；西文：**Helvetica**。全篇不引入第三族。
- 阶梯：封面主标 72 / 章节大字 64 / 巨型数字 96 / 页面主标 34 / 卡片小标 24 / 正文 18 / 图注·页码 14。

### ④ 视觉母题（每页复用）
1. 左上角 **6×26px 主色竖条** + 页面主标题（34px）+ 标题下 **1px 贯通细线**（`#E5E7EB`，宽 1160）。
2. 每张截图右下角或图下带 **14px 图注**，写明"真实界面 · 具体动作"。
3. 截图统一加 `borderRadius: 8` 与 1px `#EDE9FE` 描边，模拟应用窗口卡片。
