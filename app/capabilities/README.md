# 能力层（L1~L5）

P0 阶段仅建目录边界，验证模块化约束不越 import。具体实现见名下一批 P1 任务：

- `L1 认知挖掘`：模糊意图多轮澄清（multi-turn）
- `L2 冲突检测`：Claim 近邻 + 深度推理
- `L3 认知助产`：周简报 / 深度追问
- `L4 路径自我修正`：计划生成 / 行为偏离监测
- `L5 偏误诊断`：月健康报告 / 归因诊断

**约束**：能力模块之间禁止互相 import；能力不可直接调用模型，必须走 `app.llm.gateway`；
写入必须走 `app.domain.repositories`（强制 user_id 过滤）。
